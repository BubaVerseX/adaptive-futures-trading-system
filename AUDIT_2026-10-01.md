# Audit — 2026-10-01

Question asked: can this bot be made to trade a ~$20 Bybit account at a profit?
Scope: code review plus fixes only. No orders placed, no API keys used, and the
`STOP_BOT.txt` / `I_HAVE_A_BACKTESTED_EDGE` live-trading locks are unchanged.

## Short answer

Not yet, and not with the strategies that traded live. The live evidence in
`TRADING_STATUS.md` (384 real trades: gross −$0.84, fees $6.32, net −$7.16)
is solid and is not affected by anything below. Those were 5m/15m intraday
strategies, and fees are what killed them.

The **daily trend (Donchian) backtest**, though, which drove the "0 of 39
symbols" and "buy-and-hold beat it by 26 points" conclusions, had two flaws
that both made the strategy look worse than it is. So the case against
*low-frequency* trend following isn't closed yet. It needs a re-run with the
fixed scripts.

## Findings

### 1. Fees overcharged ~8x in the daily trend backtest (fixed)
`scripts/backtestDailyTrend.cjs`, risk-based sizing: the 14 bps round-trip fee
was subtracted from **full equity** on every trade. At 1% risk with a ~8% ATR
stop, the position is only ~12% of equity, so the real fee is ~1.7 bps of
equity. Over ~30 trades per symbol, that understated each symbol's return by
roughly 3–4 percentage points. That's large next to the reported +0.93% average.

Fix: fees now scale with the position's notional (`riskPct / stopDistancePct`).
I also added a conservative funding cost (3 bps/day on notional, charged to
longs and shorts alike), which the old backtest ignored.

### 2. Buy-and-hold comparison wasn't like-for-like (fixed in report output)
The strategy holds ~5–15% of equity in the market on average, while buy-and-hold
holds 100%. "+0.93% vs +26.67%" is mostly exposure, not skill. The backtesters
now print average exposure and buy-and-hold scaled to that exposure.

### 3. The "0 of 39" test was too weak to detect an edge (pooled test added)
Each half-window has ~10–15 trades per symbol, too few to tell edge from noise
either way. `backtestBroadTrend.cjs` now also pools every trade across all
symbols and prints the mean per-trade result with a t-statistic. Symbols are
correlated, so read the t-stat as optimistic.

### 4. Test suite was failing (fixed)
`npm test` crashed on its second test, because the mainnet edge guard added
on 2026-07-16 rejected the existing live-config test fixtures. The test file
now satisfies the guard in-memory (it never creates `EDGE_EVIDENCE.md` on disk),
and a new `testMainnetEdgeGuardBlocksWithoutEvidence` checks that the guard
still blocks live trading when the flag or the evidence file is missing.
The full suite passes.

## $20 account: a hard constraint

Bybit's minimum order value is **5 USDT**, and BTC/ETH have minimum quantities
worth far more than that. With the daily trend system as designed (1% risk,
2×ATR stop of ~8%), a $20 account risks $0.20 per trade, which means a ~$2.50
position. That's below the minimum, so **every order would be rejected**. Options:

- **2–3% risk per trade** on $20 → $5–7.50 positions, on mid-priced coins only
  (not BTC; ETH depends on its current minimum quantity). Higher risk per trade
  means bigger drawdowns. See the Monte Carlo table in `TRADING_STATUS.md`.
- **Fund ~$50+** to keep 1% risk while clearing the minimum.

The intraday v33 setup ($9 notional, 20× leverage) isn't a candidate either
way: its live record is negative.

## What to run next (on a machine that can reach api.bybit.com)

This audit ran in a cloud container that can't reach Bybit, so the re-test
still has to happen on your machine:

```bash
node scripts/backtestBroadTrend.cjs --top 40 --days 1095 --refresh
```

Use 3 years, not 2. Then judge the result on the bar already written in
`EDGE_EVIDENCE_TEMPLATE.md`, plus:
- pooled t-stat > 2 **and** positive after fees + funding;
- strategy return beats **exposure-scaled** buy-and-hold;
- holds in both halves on the pooled set, not per symbol.

If it passes: paper-trade the daily pilot (`DRY_RUN=true`) for at least 4–8
weeks before any real money. If it fails: that's a properly checked "no", and
the honest alternative is the one already on file. Buy-and-hold beat
everything tested.
